# Historical calibration photographs

These 22 images belong to the inherited real-camera experiment. They are retained
for provenance, not for calibrating a different Pi camera/lens/mode. Capture a new
set under a fresh `camera/runs/` directory using [the camera guide](../README.md).
The legacy `camera_calibration.py` deletes its configured image directory on a
new capture run; prefer the new non-destructive tools.
