# Recovered experimental source

This folder preserves useful unmerged source without enabling it in the active
2027 runtime. Exact commits, models, stashes and patches are also retained in the
[history archive](../docs/history/README.md).

- [movement](movement/README.md): go-to-goal controller from `f593fd8`.
- [simulation](simulation/README.md): SDF/xacro source from S7 local strategy tip
  `546ec2b`, two commits ahead of its cached remote.

No SolidWorks designs are recovered. Existing/experimental simulator geometry is
historical reference, not a mechanical design recommendation. Read the
[recovery report](../docs/RECOVERY.md) before porting any part.
